# Инструкция CoDuels

## Установка на виртуальную машину

0. Пререквизиты:
    - ubuntu >= 20.04
    - установлен docker

1. Скачать пакет с box-конфигурацией (вместо ${CODUELS_VERSION} требуется указать версию релиза CoDuels):
    ```bash
    wget https://github.com/DIvanCode/CoDuels/releases/download/v${CODUELS_VERSION}/coduels-box.zip
    ```

2. Разархивировать скачанный пакет с box-конфигурацией:
    ```bash
    unzip coduels-box.zip
    ```

3. Перейти в директорию с box-конфигурацией.

4. Задать переменные окружения в файле `.env`.
    - `JWT_TOKEN_SECRET_KEY` --- указать любую строку из латинских букв и цифр длины не менее 32 символов.
    - `POSTGRES_PASSWORD` --- указать любуб строку из латинских букв и цифр длины не менее 8 символов.

5. Запускить контейнеры с сервисами CoDuels:
    ```bash
    docker compose up -d
    ```

## Удаление контейнеров и базы данных

1. Удалить все контейнеры:
    ```bash
    docker rm -f $(docker ps -aq)
    ```

2. Удалить сохраненные данные БД:
    ```bash
    docker volume rm $(docker volume ls -q)
    ```


## Конфигурация CoDuels

Файл `.env` содержит переменные конфигурации, которые НЕОБХОДИМО задать перед первым запуском CoDuels.

Файл `docker-compose.yml` содержит конфигурацию, необходимую для запуска всех сервисов CoDuels.
В нем настраивается сетевая связность между компонентами системы.
Для успешного запуска и работы CoDuels не требуется изменять указанные значения.

Файл `nginx.conf` содержит конфигурацию nginx,
который используется для маршрутизации запросов между сервисами.
Для успешного запуска и работы CoDuels не требуется изменять указанную конфигурацию.

Директория `config` содержит конфигурацию всех сервисов CoDuels.
Каждое поле имеет комментарий, в котором описано, для чего оно предназначается.
Для успешного запуска и работы CoDuels не требуется изменять указанные значения.

Задачи лежат в директории `tasks/storage`.
Каждая задача имеет уникальный идентификатор, состоящий из 40 символов (вручную задавать его не требуется).
Пакет с box-конфигурацией содержит одну стандартную задачу A+B.

Файл `upload-task.sh` используется для загрузки новых задач в систему.

## Загрузка задачи

1. Перейти в директорию с box-конфигурацией.

2. Запустить скрипт для загрузки задачи:
    - `<problem.zip>` --- путь к пакету с задачей в формате polygon-linux.
    - `<level>` --- оценка сложности задачи от $1$ до $10$ ($1$ --- простая, $10$ --- сложная).
    ```bash
    bash upload-task.sh <problem.zip> <level>
    ```
