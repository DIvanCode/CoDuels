# CoDuels Box

Автономная single-host поставка CoDuels. Для запуска нужны Docker Engine и
Docker Compose plugin.

## Запуск

Release-архив содержит `.env` с версией всех CoDuels-образов. При запуске из
репозитория версию можно указать самостоятельно:

```bash
export CODUELS_VERSION=1.0.1
docker compose up -d
```

Перед публичным запуском замените все значения `CHANGE_ME` в
`docker-compose.yml` и `env/duely.env`.

## Загрузка Polygon-задачи

Передавайте ZIP-пакет Polygon и уровень сложности от 1 до 10:

```bash
./upload-task.sh /path/to/problem.zip 3
```

Скрипт скачает соответствующий release-образ
`divancode74/coduels-task-uploader`, преобразует пакет и атомарно добавит задачу
в `./tasks/storage`. Работающий Taski увидит новую задачу без перезапуска.

Повторная загрузка задачи с тем же Polygon `short-name` завершается ошибкой и
не заменяет существующую задачу. Одновременно допускается только одна загрузка.

Uploader предназначен только для доверенных административных Polygon-пакетов.
Если пакет не содержит ожидаемых ответов, uploader компилирует и запускает его
основное решение в изолированном от сети контейнере, который при этом имеет
доступ на запись к task storage.

Каталог `./tasks` содержит постоянные данные. Включайте его в резервные копии и
не удаляйте при обновлении Box.
